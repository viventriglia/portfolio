Privacy Policy

Last updated: 14 September 2026

This is a personal portfolio website. It does not use analytics, advertising, profiling technologies or contact forms, and it does not intentionally collect information directly from visitors.

Hosting and technical data

This website is hosted by GitHub Pages, a service provided by GitHub, Inc. When a GitHub Pages site is visited, GitHub logs technical information including the visitor's IP address for security purposes. This processing is necessary to deliver and protect the website and is based on the legitimate interests in providing a secure, reliable service.

The website owner does not receive or independently analyse these server logs. GitHub processes and retains this information under its own policies. For details, see the GitHub General Privacy Statement.

Local storage, cookies, assets, and external links

The website does not set cookies. Fonts and icon files are hosted locally with the website. Loading a page therefore does not contact Google Fonts, Font Awesome, Academicons or their content delivery networks.

The website contains links to external services such as GitHub, LinkedIn, Google Scholar, YouTube, Spotify and PyPI. No data is sent to those services merely because a link appears on this website; their own privacy policies apply after a visitor chooses to follow a link.

Recipients and international transfers

Technical data required to serve the website may be processed by GitHub and its service providers, including outside the European Economic Area, subject to the safeguards described in GitHub's privacy statement.

Your rights

Where the GDPR applies, visitors may request access, rectification, erasure or restriction of their personal data, object to processing, and exercise any other applicable data-protection rights by contacting the controller. Visitors also have the right to lodge a complaint with the Italian Data Protection Authority or their competent supervisory authority.

Changes to this policy

This notice may be updated if the website or the services it uses change. The revision date shown above identifies the current version.
